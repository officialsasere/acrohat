# Changelog

## Kwiiva Write 0.1.0 – first release
- A document editor with real pages (Letter, A4, A5, Legal, A3), margins, headers, footers and page numbers; fonts, styles, lists, checklists, tables, pictures, links, table of contents, find and replace, outline, templates.
- Opens and saves .docx (own reader and writer), plus HTML, Markdown and plain text; print or save as PDF.
- Drafts autosave on the device. Works on phones and tablets and installs to the home screen.
- Desktop apps for Windows, macOS and Linux.

## Website and counters
- Public, anonymous counters of downloads and app launches on the Kwiiva site, with a switch in each app to turn the launch count off.

## 0.1.0 – Kwiiva Paper, first release
- Edit text and images in place, annotate, fill and create forms, certificate signatures with validation, redaction, OCR, PDF/A, accessibility tagging, convert (DOCX, text, images), compare.
- Desktop apps for Windows, macOS and Linux, plus a web version that also works on phones and tablets (install it from the browser).
- Familiar layout: left icon rail, page thumbnails, bookmarks and a right-hand Tools pane.
- Part of **Kwiiva**, a family of free, open-source apps. Website, one-click downloads and contributor guide included.
