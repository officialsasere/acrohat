# Changelog

## All apps
- **Automatic saving**: once a file has been saved, changes are written to it by themselves. Switch it off in the File menu (Kwiiva Paper: the Auto button).
- Saving in the desktop apps no longer depends on the general file plugin, and error messages now say what went wrong.

## Kwiiva Present 0.1.0 – first release
- A presentation app: ten themes with eight layouts, an editable slide master, text with bullets and numbering, nearly 90 shapes, lines and connectors, pictures, tables, charts, audio and video.
- Animations (entrance, emphasis, exit) and slide transitions; a full-screen show with pen, highlighter and laser pointer, a presenter view with notes and a timer, and an audience window.
- Opens and saves .pptx (written and read without a library); exports PDF, PNG pictures, a one-file web page and an outline; makes slides from a Markdown outline.
- Works on phones and tablets and installs to the home screen. Desktop apps for Windows, macOS and Linux.

## Kwiiva Grid 0.1.0 – first release
- A spreadsheet with 409 functions, dynamic arrays, LET/LAMBDA, named ranges and number formats.
- Formatting, merged cells, freeze panes, conditional formatting (including colour scales and data bars), data validation with drop-downs and check boxes, sorting, filters, pivot tables, charts, find and replace.
- Opens and saves .xlsx and .csv; charts and notes also come back when a file is reopened here.
- Works on phones and tablets and installs to the home screen. Desktop apps for Windows, macOS and Linux.

## Kwiiva Write 0.1.0 – first release
- A document editor with real pages (Letter, A4, A5, Legal, A3), margins, headers, footers and page numbers; fonts, styles, lists, checklists, tables, pictures, links, table of contents, find and replace, outline, templates.
- Opens and saves .docx (own reader and writer), plus HTML, Markdown and plain text; print or save as PDF.
- Drafts autosave on the device. Works on phones and tablets and installs to the home screen.
- Desktop apps for Windows, macOS and Linux.

## Website and counters
- Public, anonymous counters of downloads and app launches on the Kwiiva site, with a switch in each app to turn the launch count off.

## 0.1.0 – Kwiiva Paper, first release
- Edit text and images in place, annotate, fill and create forms, certificate signatures with validation, redaction, OCR, PDF/A, accessibility tagging, convert (DOCX, text, images), compare.
- Desktop apps for Windows, macOS and Linux, plus a web version that also works on phones and tablets (install it from the browser).
- Familiar layout: left icon rail, page thumbnails, bookmarks and a right-hand Tools pane.
- Part of **Kwiiva**, a family of free, open-source apps. Website, one-click downloads and contributor guide included.
