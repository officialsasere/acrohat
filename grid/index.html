Installing an unsigned app

Kwiiva Grid is a free project and the installers are not yet signed with paid developer certificates, so your OS will warn you the first time:

macOSDrag Kwiiva Grid to Applications, then right-click → Open → Open (once). If macOS says the app is "damaged", run xattr -cr "/Applications/Kwiiva Grid.app" in Terminal.
WindowsIf SmartScreen appears, choose More info → Run anyway.
LinuxMake the AppImage executable (chmod +x) and run it, or install the .deb.

Prefer to verify? The source is public and the installers are built by public GitHub Actions runs.
