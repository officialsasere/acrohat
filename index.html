Installing an unsigned app

Acrohat is a free project and the installers are not yet signed with paid developer certificates, so your OS will warn you the first time:

macOSDrag Acrohat to Applications, then right-click → Open → Open (once). If macOS says the app is "damaged", run xattr -cr /Applications/Acrohat.app in Terminal.
WindowsIf SmartScreen appears, choose More info → Run anyway.
LinuxMake the AppImage executable (chmod +x) and run it, or install the .deb.

Prefer to verify? The source is public and the installers are built by public GitHub Actions runs.

Honest comparison with Acrobat

Acrohat covers the everyday and a lot of the professional toolkit. It is not a 1:1 clone: Acrobat is 30 years of work plus cloud services.

Not availableAdobe Sign and other cloud services, PDF/X and full print Preflight, XFA forms, 3D/multimedia, creating PDFs from Word/Excel/PowerPoint files, Excel/PowerPoint export (Word export is text and headings only).
PartialText editing works within a paragraph (not across columns or pages). Signatures are certificate-based but trust is up to the recipient (self-signed certificates show as unverified). OCR is English only. PDF/A conversion and the accessibility tagger are automatic and have not been certified by the official validators (veraPDF, PAC); check important files with them.
